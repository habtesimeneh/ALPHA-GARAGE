## 1. BACKLOG CLASSIFICATION METHODOLOGY

Every finding in this backlog is derived from line-by-line inspection of actual application code and CSS stylesheets. Findings are categorized into four standard engineering priorities:

- **P0 — Critical Usability or Functional Bug:** Renders screens broken, triggers network HTTP errors (404), or destroys readability on supported devices.
- **P1 — High-Impact Usability or Visual Flaw:** Severely impedes daily user workflows, creates visual identity incoherence, or violates core accessibility standards.
- **P2 — Medium-Priority Improvement:** Suboptimal information architecture, missing operational shortcuts, or layout crowding that creates user friction.
- **P3 — Minor Polish or Optional Enhancement:** Visual refinements, micro-interactions, or secondary progressive enhancements.
